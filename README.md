# 📝 Blog Web Application

A full-stack blog web application where users can register, log in securely, create and manage their own blog posts, and share posts with images and videos.

## 🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- 🔒 Protected API Routes
- 📝 Create Blog Posts
- ✏️ Edit Your Blog Posts
- 🗑️ Delete Your Blog Posts
- 🖼️ Upload Images
- 🎥 Upload Videos
- 👤 Author Name Display
- 📅 Post Creation Date
- 📱 Responsive Design
- 🔓 Session-based Frontend Authentication
- 🗄️ PostgreSQL Database
